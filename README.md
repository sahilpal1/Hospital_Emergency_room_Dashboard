# Hospital_Emergency_room_Dashboard
🏥 Hospital Emergency Room Dashboard
📌 Project Overview

This project is an interactive Hospital Emergency Room Dashboard developed using Microsoft Power BI. The dashboard provides real-time insights into patient admissions, waiting times, satisfaction scores, age distribution, gender analysis, and department referrals. It helps healthcare administrators monitor hospital performance and improve patient care services.

🎯 Project Objectives
Track emergency room patient flow.
Monitor admission and non-admission rates.
Analyze patient satisfaction levels.
Measure average waiting time.
Identify age-group distribution of patients.
Evaluate department referral patterns.
Support data-driven healthcare decisions.
